#### What this proposes
This design introduces an out-of-tree Apache NuttX board support package (`xiao-rp2350-bargraph/board/`) and built-in application (`xiao-rp2350-bargraph/apps/bargraph/`) for a Seeed Studio XIAO RP2350 connected to a linear potentiometer on `D0/A0` (`GPIO26`) and six LEDs on `D1`–`D6` (`GPIO27`, `GPIO28`, `GPIO5`, `GPIO6`, `GPIO7`, `GPIO0`). At boot, `board_late_initialize()` invokes `rp23xx_bringup()` to register `/dev/adc0` and `/dev/pwm0,2,3,5,6`, isolate the `GPIO26` digital pad to prevent RP2350-E9 leakage, and launch a background daemon (`bargraphd`) before NSH blocks waiting for a USB-C CDC/ACM host connection. The daemon samples `ADC0` at 50 Hz using demand-driven NVIC interrupt gating (`up_enable_irq`/`up_disable_irq` around a 5-sample burst after `ANIOC_RESET_FIFO`), smooths and clamps the reading with a Q4 exponential moving average and endpoint deadbands, and drives the six LEDs across five 1 kHz hardware PWM slices with proportional 16-bit duty cycles (`0..65535`). An interactive `bargraph` NSH command coordinates with `bargraphd` over shared memory (`g_bargraph` mutex and condition variables) to support `start`, `stop`, `status`, `test`, `set <0..100>`, and `resume` while keeping the `nuttx/` and `apps/` submodules completely unmodified.

#### How the existing system works, per this document
In the upstream `nuttx/` and `apps/` submodules, the default `xiao-rp2350:usbnsh` board configuration omits `CONFIG_BOARD_LATE_INITIALIZE=y` (leaving `/dev/adc0` and `/dev/pwm*` unregistered) and blocks inside `nsh_waitusbready()` until a USB host opens `/dev/ttyACM0` and sends three newline or carriage-return characters. In `nuttx/arch/arm/src/rp23xx/rp23xx_pwm.c`, multi-channel support is gated on `CONFIG_PWM_NCHANNELS == 2` (while the arch Kconfig defines `CONFIG_RP23XX_PWM_MULTICHAN` and `CONFIG_RP23XX_PWM_NCHANNELS`), channel duties are indexed positionally (`channels[0]` -> channel A, `channels[1]` -> channel B) and stored in `uint16_t` (causing `b16ONE = 65536` to truncate to `0`), and `PWMIOC_STOP` disables the PWM slice without driving the GPIO low until `close()` calls `pwm_shutdown()`. In `nuttx/arch/arm/src/rp23xx/rp23xx_adc.c`, registering `/dev/adc0` resets `GPIO26`–`GPIO29` to `RP23XX_GPIO_FUNC_NULL` while leaving `IE=1` set on `GPIO26` (triggering erratum RP2350-E9 pad leakage), scans all enabled channels round-robin, shifts 12-bit conversion values left by 19 bits, and unconditionally re-triggers `START_ONCE` inside `interrupt_handler()` at 500,000 conversions/second whenever `RP23XX_ADC_IRQ_FIFO` is unmasked. For out-of-tree extensibility, NuttX supports `CONFIG_ARCH_BOARD_CUSTOM` for external board directories and `apps/Make.defs` includes `$(TOPDIR)/Make.defs` prior to scanning `$(APPDIR)/*/Make.defs`, allowing a symlink at the git-ignored `apps/external` path to register external applications.
